Healthcare Data Analysis Dashboard | Power BI

* Project Overview

This project focuses on analyzing hospital and healthcare management data using Microsoft Power BI. The dashboard helps explore patient demographics, treatment costs, patient status, length of stay, feedback, and ratings.

The goal is to convert raw healthcare data into meaningful visual insights that can support hospital performance monitoring and data-driven decision-making.

* Tools & Technologies

Microsoft Power BI – Dashboard development and data visualization

Microsoft Excel – Healthcare dataset

Power Query – Data preparation and transformation

DAX – Calculated measures and KPIs, where applicable

* Dataset

The dataset contains healthcare and hospital management information, including:

Patient details and demographics

Patient type and status

Treatment costs

Length of stay (LOS)

Emergency room time

Patient feedback and ratings

Staff, department, and bed details

* Project Objectives

Analyze patient demographics and patient types.

Explore treatment costs and length of stay.

Understand patient feedback and satisfaction ratings.

Examine healthcare data across departments and other available categories.

Present key information through interactive Power BI visualizations.

* Project Files

Healthcare Power BI.pbix – Power BI dashboard file

Hospital Health Care Management Data set.xlsx – Source dataset

* Skills Demonstrated

Data analysis

Data cleaning and preparation

Data visualization

Power BI dashboard development

Healthcare KPI analysis

* How to Explore

Download the Power BI .pbix file.

Open it using Microsoft Power BI Desktop.

If prompted, update the source file path to the downloaded Excel dataset.

Refresh the data if required.

Explore the dashboard and its available filters and visuals.

* Conclusion

This project demonstrates how Power BI can be used to analyze healthcare data and present information in an accessible visual format. It showcases practical data analytics skills relevant to entry-level Data Analyst roles.
